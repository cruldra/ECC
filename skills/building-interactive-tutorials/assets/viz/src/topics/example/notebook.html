示例

简介

既讲它是什么，也讲为什么需要它：示例把一个词拆开、合并，再查词表换成一串编号，因为后面的程序只认编号、不认文字。这讲的是一个机制，所以紧跟一个演示，不能只有文字：

In
word = "hello"
vocab = ["h", "e", "l", "o", "ll"]

# 拆分与合并：拆成字母，挨着的两块拼起来在词表里就并成一块
letters = list(word)
pieces = []
for ch in letters:
    if pieces and pieces[-1] + ch in vocab:
        pieces[-1] += ch
    else:
        pieces.append(ch)
print(letters, pieces)

# 词表共几项，演示画出的是哪几项
print(len(vocab), {vocab.index(p): p for p in pieces})

# 查表：每块换成编号，再按编号反查拼回
ids = [vocab.index(p) for p in pieces]
print(ids, "".join(vocab[i] for i in ids))
Out
['h', 'e', 'l', 'l', 'o'] ['h', 'e', 'll', 'o']
5 {0: 'h', 1: 'e', 4: 'll', 3: 'o'}
[0, 1, 4, 3] hello

预分词

按空格切块

按空格切块是最直接的预分词：遇到空格、换行这类空白就切开，空白本身扔掉，标点和字母留在同一块里。HuggingFace tokenizers 里对应 pre_tokenizers.WhitespaceSplit，常和别的预分词器串起来用。

使用场景

  • 本示例
  • Pegasus

拆分与合并

BPE

BPE（字节对编码）本来是一种数据压缩算法，后来被用到分词上：反复把一起出现最多的相邻两块并成一块，常见组合成了一个 token，罕见的词拆成小片段也能表示，词表不用很大。HuggingFace tokenizers 里对应 models.BPE。

使用场景

  • 本示例
  • GPT-2
  • Llama 3

表格输出

输出是一张表时，让命令打印 JSON，把每个值原样放进 out-table 的一格。命令行对齐列时一个汉字只算一格，浏览器里却占两格，直接贴文本列就歪了：

In
import json
from collections import Counter
print(json.dumps([{"字母": c, "次数": n} for c, n in Counter("hello").items()], ensure_ascii=False))
