# 交付物规格

三份对外文档的骨架与必填项。**必填项缺一项都不许发出。**

---

## 一、报价方案

文件名：《{项目名}开发报价方案》　源文件写 markdown，用 pandoc 转 docx/pdf 发客户。

### 必填项检查表

| # | 必填项 | 漏掉的后果 |
|---|---|---|
| 1 | 编制单位、文档版本号、出具日期 | 版本混乱，客户拿旧版谈 |
| 2 | **报价有效期**（默认 30 个自然日） | 客户拖三个月后拿旧价签 |
| 3 | 金额大写 + 小写并列 | 不符合商务规范 |
| 4 | 付款节点与比例、首付金额（大小写） | 回款无依据 |
| 5 | 发票税率与发票内容 | 财务对不上 |
| 6 | **不包含费用清单**（服务器、域名、Token、短信、平台年审费） | 第三方费用被默认包含 |
| 7 | **本期范围说明**（明确不做什么） | 需求蔓延无边界 |
| 8 | 甲方前置义务 + **交付顺延条款** | 客户不给资料却怪你延期 |
| 9 | AI 项目的**量化验收标准** | 无限返工 |
| 10 | **保密声明** | 报价被拿去比价 |
| 11 | 附录 · 功能页面总览（与原型一一对应） | 范围口径不一致 |

### 章节骨架

```
标题 + 编制单位 / 文档版本 / 出具日期 / 报价有效期
一、项目背景与理解        ← 客户全称（以下简称"甲方"）+ 复述其业务痛点，证明听懂了
二、建设目标              ← 可度量的目标，不写形容词
三、团队配置与报价明细    ← 角色 / 人数 / 投入周期 / 职责 + 报价说明（含不包含费用）
四、功能范围              ← 编号表 01…N，与原型对应
五、项目周期与里程碑      ← M1…Mn，每阶段有交付物
六、技术方案（概要）      ← 层级 / 选型表，见 company-profile.md
七、交付物清单            ← 源码 / 文档 / 部署 / 培训 / 知识产权
八、售后服务              ← 维保期 + 响应时效 SLA
九、双方职责              ← 甲方前置义务 + 交付顺延条款
十、风险与保障            ← 风险 / 应对 两列表
十一、本期范围说明        ← 明确不做什么
十二、报价汇总            ← 大小写金额 + 付款方式 + 发票
附录 A · 功能页面总览
附录 B · AI 功能验收标准（有 AI 才写）
保密声明
```

### 呈现原则

- **呈现"团队配置 × 投入周期 = 固定总价"，不呈现人天明细。** 露人天等于邀请客户按人头砍价
- 团队配置表是让客户感受投入规模、建立信任的，不是成本清单
- 给两个方案（打包 / 分期）时，必须标出分期的总价更高与多出的周期，把打包的性价比摆明

## 二、技术解决方案

金额 > 30 万或客户方有技术人员时出。**和报价方案一起发**，成交率显著高于只发报价。

作用：建立"他们真的懂"的信任。客户不一定看得完，但看得出深度。

```
文档信息（版本 / 日期 / 编制人）
1. 执行摘要        ← 项目概述 / 核心价值主张 / 技术方案要点
2. 背景与需求      ← 业务背景 / 核心痛点 / 功能需求清单
3. 系统架构        ← 总体架构 / 层级详解 / 技术栈全景 / 数据架构 / API 设计 / 部署架构
4. 关键技术方案    ← 逐个攻克难点，带伪代码。这一章是信任的来源
5. 实施计划        ← 里程碑 / 阶段划分 / 资源配置 / 交付物标准
6. 风险评估与应对
7. 附录            ← 技术栈汇总 / 模型候选 / 参考文档
```

第 4 章是重点：**把客户最担心的那几个技术难点单独拎出来讲透**，配伪代码和架构图。

## 三、合同

以《{项目名}系统服务合同》为名。条款库见 `contract-clauses.md`。

### 必备条款

```
甲乙双方主体信息（全称 / 地址 / 联系人 / 电话）
一、项目服务内容        ← 项目概述 + 功能需求 F1…Fn（与报价方案功能范围逐条对应）
二、项目开发周期及阶段  ← 起止日期 + 阶段表
三、项目费用及支付方式  ← 总额大小写 / 付款节点 / 第三方费用归属 / 收款账户 / 发票
四、项目验收交付        ← 软件 + 文档 + 质量三类交付 + AI 量化验收标准
五、知识产权归属        ← 归属 / 源码交付要求 / 禁止复用 / 侵权责任 / 交付后义务终止
六、售后服务
七、双方的权利与义务    ← 含甲方资料提供义务与顺延条款
八、保密条款
九、违约责任
十、合同的生效及终止
十一、争议解决
十二、其他条款
```

### 一致性校验

合同发出前逐条比对：

- 合同"功能需求 F1…Fn" ⊇ 报价方案"功能范围 01…N" ⊇ 原型页面清单
- 合同金额 = 报价方案金额（含大写）
- 合同周期 = 报价方案里程碑总周期
- 合同"不含第三方费用"清单 = 报价方案"不包含费用"清单

**任何一处不一致，客户都会挑最有利于他的那一版执行。**
