# Token 预算顾问（TBA）

在 Claude 作答之前拦截响应流程，让用户选择回答深度。

## 适用情形

- 用户想控制回答的长度或详细程度
- 用户提到 tokens、预算、深度或回答长度
- 用户说“简短版”“tldr”“简要”“按 25%”“详尽”等
- 用户想提前选择回答深度或详细程度时

**不要触发**：用户本次会话已设定级别（静默保持该级别），或答案只有一行且非常简单。

## 工作方式

### 第 1 步 — 估算输入 token 数

使用仓库中规范的上下文预算启发式方法，在心里估算提示词的 token 数。

使用与 [context-budget](../context-budget/SKILL.md) 相同的校准指引：

- 普通文本：`words × 1.3`
- 代码较多或混合内容/代码块：`chars / 4`

混合内容按占主导的内容类型估算，并保持启发式估算。

### 第 2 步 — 根据复杂度估算响应大小

对提示词分类，然后应用乘数范围，得到完整响应区间：

| 复杂度 | 乘数范围 | 示例提示 |
|--------------|------------------|------------------------------------------------------|
| 简单 | 3× – 8× | “X 是什么？”，是/否问题，单一事实 |
| 中等 | 8× – 20× | “X 是如何工作的？” |
| 中等偏高 | 10× – 25× | 带有上下文的代码请求 |
| 复杂 | 15× – 40× | 多部分分析、比较、架构设计 |
| 创意类 | 10× – 30× | 故事、文章、叙事写作 |

响应区间 = `input_tokens × mult_min` 到 `input_tokens × mult_max`（但不得超过模型配置的输出 token 上限）。

### 第 3 步 — 提供深度选项

在回答前，使用实际估算数字提供以下内容：

```
正在分析你的提示词……

输入：约 [N] tokens  |  类型：[type]  |  复杂度：[level]  |  语言：[lang]

选择回答深度：

[1] 精简版   (25%)  ->  约 [tokens]   只给直接答案，不作铺垫
[2] 适中版   (50%)  ->  约 [tokens]   答案 + 背景 + 1 个示例
[3] 详细版   (75%)  ->  约 [tokens]   完整回答并提供替代方案
[4] 穷尽版 (100%)  ->  约 [tokens]   涵盖所有内容，不设限制

选择哪个级别？（1-4，或说“25% 深度”“50% 深度”“75% 深度”“100% 深度”）

精确度：启发式估算，准确率约 85-90%（±15%）。
```

各级别的 token 估算（位于响应区间内）：
- 25% → `min + (max - min) × 0.25`
- 50% → `min + (max - min) × 0.50`
- 75% → `min + (max - min) × 0.75`
- 100% → `max`

### 第 4 步 — 按所选级别作答

| 级别 | 目标长度 | 包含内容 | 省略内容 |
|------------------|---------------------|-----------------------------------------------------|---------------------------------------------------|
| 25% 精简版 | 最多 2-4 句 | 直接回答、关键结论 | 背景、示例、细微差异、替代方案 |
| 50% 适中版 | 1-3 段 | 答案 + 必要背景 + 1 个示例 | 深入分析、边缘情况、参考资料 |
| 75% 详细版 | 结构化回答 | 多个示例、优缺点、替代方案 | 极端边缘情况、详尽参考资料 |
| 100% 穷尽版 | 不限 | 所有内容——完整分析、全部代码、所有视角 | 无 |

## 快捷选项 — 跳过提问

如果用户已经明确表示所需级别，立即按该级别回答，不必询问：

| 用户说法 | 级别 |
|----------------------------------------------------|-------|
| “1” / “25% depth” / “short version” / “brief answer” / “tldr” | 25% |
| “2” / “50% depth” / “moderate depth” / “balanced answer” | 50% |
| “3” / “75% depth” / “detailed answer” / “thorough answer” | 75% |
| “4” / “100% depth” / “exhaustive answer” / “full deep dive” | 100% |

如果用户在本次会话较早时设定了级别，后续回答中**静默保持该级别**，除非用户更改设定。

## 精确度说明

此技能使用启发式估算，不使用真实的 tokenizer。准确率约为 85-90%，误差 ±15%。始终展示免责声明。

## 示例

### 会触发

- “先给我简短版。”
- “你的回答会用多少 tokens？”
- “按 50% 深度回答。”
- “我想要详尽回答，不要摘要。”
- “Dame la version corta y luego la detallada.”

### 不会触发

- “JWT token 是什么？”
- “结账流程使用支付 token。”
- “这正常吗？”
- “完成这次重构。”
- 用户已经为本次会话选择深度后的后续问题
